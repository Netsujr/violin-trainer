# Violin reference notes

One recording for each note of first position, G3 to B5, named by MIDI number (55 to 83). Practice's reference
button and the piece editor's play buttons sound them.

## Where they're from

The University of Iowa Electronic Music Studios' Musical Instrument Samples, violin, arco, mezzo-forte, played by
Josue Jean-Francois in an anechoic chamber: https://theremin.music.uiowa.edu/MISviolin.html. The studios say the
recordings "may be freely used for any purpose without restriction" (https://theremin.music.uiowa.edu/staff.html).

## How they were made

- Each note is the recording on the string it's played on in first position (G string up to C♯4, D up to G♯4, A up
  to D♯5, E above), whichever of that string's recorded notes was closest in pitch.
- Each is retuned to A440, measured where it loops, to within a cent.
- The bow's first 0.26 s is joined, at the point where the waveforms line up best, to the steadiest second from the
  middle of the note. That second loops seamlessly to the end of the file, crossfaded at the join, so a note can sound
  for as long as it's needed.
- They're all levelled to one loudness, and saved as 32 kHz mono FLAC, which is lossless and keeps the loop exact.
